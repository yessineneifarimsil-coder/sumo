# Route de Tunis — SUMO Microscopic Traffic Model

PhD thesis project (Sfax, Tunisia). Microscopic SUMO model of a ~13 km urban
corridor (Route de Tunis), used to study traffic flow, signal control, and
(next phase) real-time control via TraCI/Python.

## Status

- ✅ Network built (from OSM via GIS pipeline) and cleaned in NetEdit
- ✅ Traffic demand: AM / midday / PM flows + 5 lateral entries + 2 ramps
- ✅ Turn ratios calibrated for 11 major intersections (`jtrrouter`)
- ✅ Bus line 25 (10 aller + 10 retour, AM peak)
- ✅ 3 coordinated traffic signals (offsets for green wave)
- ✅ **As of this reorganization: bus + signals are now actually loaded by
  `routetunis.sumocfg`** (they weren't before — see `docs/decisions.md`)
- 🔄 Stabilizing remaining deadlock-prone junctions
- ⏳ Full 12h calibration run + KPI extraction
- 🅿️ A separate, richer "digital twin" demand model (TAZ + OD matrix) exists
  but is **not connected** to the active simulation — see `digital_twin/README.md`
- ⏳ TraCI/Python integration (next phase)

## Quick start

```bash
conda env create -f environment.yml
conda activate routetunis

bash scripts/generate_routes.sh      # or scripts\generate_routes.bat on Windows

sumo -c config/routetunis.sumocfg
# or: sumo-gui -c config/routetunis.sumocfg
```

## Key model parameters (active pipeline)

| Parameter | Value |
|---|---|
| Corridor length | ~13 km |
| Simulation window | 07:00–19:00 |
| Main flow AM / midday / PM | 1200 / 800 / 1300 veh/h |
| Lateral entries (AM) | 60, 40, 30, 25, 20 veh/h |
| Speed limit | 50 km/h (13.9 m/s) |
| Bus line 25 | 10 aller + 10 retour, AM peak, corridor → Technopole |
| Signalized junctions | 3, coordinated (offsets 0/15/30s) |
| Turn ratio calibration | 11 movements, HIGH ≈0.18 / MED ≈0.08 |
| Deadlock safety valve | `time-to-teleport=300`, `time-to-teleport.stopped=180` |

See `digital_twin/README.md` for the parallel, unconnected richer model
(8 TAZs, 9 vehicle types, OD matrix).
